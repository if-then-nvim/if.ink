1. INTRODUCTION                                                  *if-ink-intro*

if.ink paints colours where they appear in your buffer: hex literals, CSS
colour functions, named colours inside strings, and colours reported by a
language server.

Only the lines currently on screen are repainted as you type or scroll, so the
cost stays flat regardless of file size.

==============================================================================
2. REQUIREMENTS                                           *if-ink-requirements*

- Neovim >= 0.11
- 'termguicolors' enabled

==============================================================================
3. COMMANDS                                                   *if-ink-commands*

                                                                      *:IfInk*
:IfInk [subcommand]
        Without an argument, toggles highlighting in the current buffer.

        Subcommands:
            toggle    Toggle highlighting in the current buffer.
            attach    Start highlighting the current buffer.
            detach    Stop highlighting and clear the current buffer.
            reload    Repaint every attached buffer with the current options.

        An unknown subcommand reports an error and does nothing.

==============================================================================
4. LUA API                                                         *if-ink-api*

                                                             *if.ink.setup()*
require("if.ink").setup({opts})
        Applies {opts} on top of the defaults (|if-ink-config|) and
        installs the autocommands that attach matching buffers. Calling it
        is optional; the defaults apply without it.

                                                            *if.ink.attach()*
require("if.ink").attach({buf})
        Starts highlighting {buf}, defaulting to the current buffer.

                                                            *if.ink.detach()*
require("if.ink").detach({buf})
        Stops highlighting {buf} and clears its extmarks.

                                                            *if.ink.toggle()*
require("if.ink").toggle({buf})
        Attaches {buf} if detached, detaches it otherwise.

                                                            *if.ink.reload()*
require("if.ink").reload({buf})
        Repaints {buf} with the current options. Repaints every attached
        buffer when {buf} is omitted.

                                                       *if.ink.is_attached()*
require("if.ink").is_attached({buf})
        Returns true when {buf} is currently highlighted.

==============================================================================
5. CONFIGURATION                                                *if-ink-config*

Defaults: >lua

    require("if.ink").setup({
      RGB = true,
      RRGGBB = true,
      names = true,
      css_fn = true,
      lsp = true,
      mode = "background",
      virtualtext = "██",
      editor_bg = nil,
      filetypes = { "*" },
      exclusions = {},
    })
<
------------------------------------------------------------------------------
5.1 MATCHERS                                           *if-ink-config-matchers*

RGB                     boolean, default true
        Highlight three-digit hex literals such as `#f00`. All-digit matches
        such as `#123` are skipped so issue references are left alone.

RRGGBB                  boolean, default true
        Highlight six-digit hex literals such as `#ff0000`.

names                   boolean, default true
        Highlight colour names inside string literals, resolved from Neovim's
        colour map (see |nvim_get_color_map()|). A name joined to another
        token by `-`, `_` or `.` is ignored, so `border-red` and `theme.red`
        stay untouched.

css_fn                  boolean, default true
        Highlight `rgb()` and `rgba()` calls. An alpha value is blended
        against the editor background (|if-ink-config-editor-bg|).

lsp                     boolean, default true
        Render colours reported through `textDocument/documentColor`. Requests
        are debounced by 200ms and cached per buffer. While enabled, Neovim's
        built-in |vim.lsp.document_color| is disabled on attached buffers to
        avoid duplicate swatches.

------------------------------------------------------------------------------
5.2 RENDER MODES                                           *if-ink-config-mode*

mode                    string or list, default "background"
        How a match is drawn:

            "background"    paint the literal's background
            "foreground"    tint the literal's text
            "virtualtext"   draw a swatch glyph before the literal

        A list applies several at once: >lua

            mode = { "background", "virtualtext" }
<
        A colour wrapped in square brackets, `[#ff0000]`, is always drawn as a
        swatch only, keeping the literal readable. Colours reported by a
        language server behave the same way, as there is no literal for them
        to paint over.

virtualtext             string, default "██"
        Glyph used by the "virtualtext" mode.

------------------------------------------------------------------------------
5.3 FILETYPES                                         *if-ink-config-filetypes*

filetypes               string[], default { "*" }
        Filetypes to attach to. `{ "*" }` matches every buffer.

exclusions              string[], default {}
        Filetypes never attached to, even when `filetypes` would match them.

Buffers with a non-empty 'buftype' are never attached.

------------------------------------------------------------------------------
5.4 EDITOR BACKGROUND                                 *if-ink-config-editor-bg*

editor_bg               string, default nil
        A `#rrggbb` colour used for contrast checks and alpha blending. When
        nil, the background of the |hl-Normal| highlight is used.

        A colour whose WCAG contrast ratio against this background falls below
        1.3 is lightened, so a near-black swatch stays visible on a dark
        colorscheme.

6. BLINK.CMP INTEGRATION                                         *if-ink-blink*

                                                     *if.ink.blink.kind_icon()*
require("if.ink.blink").kind_icon({opts})
        Returns a blink.cmp `kind_icon` component that paints the icon of a
        `Color` completion item with the colour that item represents: >lua

            require("blink.cmp").setup({
              completion = { menu = { draw = { components = {
                kind_icon = require("if.ink.blink").kind_icon(),
              } } } },
            })
<
        {opts} accepts:
            icon        glyph drawn for colour items, default "󱓻"
            fallback    component delegated to for non-colour items

                                                        *if.ink.blink.get_hl()*
require("if.ink.blink").get_hl({item})
        Returns the highlight group for a single completion item, or nil when
        no colour can be resolved from it. For callers wiring up their own
        component.

==============================================================================
7. HIGHLIGHTS                                               *if-ink-highlights*

Highlight groups are created on demand and named: >

    ifink_<mode>_<rrggbb>
    ifink_<mode>_<rrggbb>_a<alpha>     when the colour carries transparency
<
Group names keep the colour as written; the rendered colour may differ after
contrast correction or alpha blending. The cache is rebuilt on |ColorScheme|.

==============================================================================
8. HEALTH                                                       *if-ink-health*

Run |:checkhealth| if.ink to verify the Neovim version, 'termguicolors',
whether an attached language server provides documentColor, and whether the
current buffer is highlighted.
